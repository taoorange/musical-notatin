# `枫（钢琴版）周杰伦_爱给网_aigei_com.musicxml`：出现过的 MusicXML 标签含义表

> 说明：含义按 MusicXML 规范语义整理；结合该文件里常见的组织方式（例如 `measure/note/pitch/type/duration`）补充“通常用在什么上下文”。

| 标签 | 常见位置/上下文 | 含义（一句话） | 典型值/例子 |
|---|---|---|---|
| `accidental` | `note/pitch`附近 | 音符实际要显示的临时变化记号类型（升/降/还原等） | `sharp` / `flat` / `natural` |
| `actual-notes` | `time-modification` | 复拍（tuplet）中“实际音符数量” | `3`（三连音常见） |
| `alter` | `pitch` | 音高的半音升降偏移（相对自然音） | `-1/0/1` 等 |
| `appearance` | 页面/符号外观 | 排版外观参数容器（外观相关的父节点） | 容器 |
| `articulations` | `notations` 内 | 连音/断音等“表现类记号”的容器 | 容器/空元素 |
| `attributes` | `measure` 内 | 小节/段落的音乐属性声明（拍号、调号、谱号、节奏单位等） | 容器 |
| `backup` | `measure` 内（多声部） | 将当前时间游标向后回退（用于在同一小节写多个 `voice`） | 与 `duration`配合 |
| `bar-style` | `barline` | 小节线样式（端点/结束线等外观特征） | 样式名 |
| `barline` | `measure` | 小节线容器（开始/结束/常规等） | 容器 |
| `beam` | `note`节奏分组（通常在 `notations` 内） | 连音/连梁分组信息（八分、十六分等的连线） | 与 `type`/时值相关 |
| `beat-type` | `time` | 拍号的“类型/分母风格”（与 `beat-unit`配套） | `4`/`8` 等风格化表达 |
| `beat-unit` | `time` 或速度/节拍相关 | 拍号/节拍器的“单位音符类型”（如 `quarter`） | `quarter` 等 |
| `beats` | `time` | 拍号分子（每小节多少拍） | `4` 等 |
| `bottom-margin` | `page-margins` | 页脚边距 | 数值 |
| `clef` | `attributes` | 谱号（决定五线谱基准与音高映射） | 与 `sign/line`一起 |
| `defaults` | 编码/布局默认值 | 默认参数容器（例如默认字体/位置/尺度等） | 容器 |
| `direction` | `measure` | 方向/标记容器（速度、力度、文字等信息通常放这里） | 容器 |
| `direction-type` | `direction` 内 | `direction` 的具体类型（例如 tempo） | 容器 |
| `divisions` | `attributes` | 节奏单位换算：定义 `duration` 的基准分割数 | 数值 |
| `dot` | `note` | 附点（延长时值，如附点让时值变为原来的 1.5 倍） | 通常为“点的个数”/空元素 |
| `duration` | `note` | 音符/休止符时值（以 `divisions` 为单位计量） | 数值 |
| `encoding` | 文件头 | 编码与导出工具能力/支持声明的容器 | 容器 |
| `encoding-date` | 文件头 | 导出/编码日期 | `YYYY-MM-DD` |
| `fifths` | `key` | 调号（五度圈）中的升/降号数量 | 负/正整数 |
| `forward` | `measure` 内 | 将当前时间游标向前推进（用于跳过时间段/对齐） | 与 `duration`配合 |
| `identification` | 文件头 | 作品/作者/平台等识别信息容器 | 容器 |
| `instrument-name` | `score-instrument` | 乐器名称（语义/显示用） | `Piano` 等 |
| `instrument-sound` | `score-instrument` | 与乐器音色/标识相关的信息 | 可能为标识/名称 |
| `key` | `attributes` | 调号容器（由 `fifths` 等给出） | 容器 |
| `left-margin` | `page-margins` / `system-margins` | 左边距 | 数值 |
| `line` | `clef` | 谱号在五线谱中的线序号（例如高音谱号落在哪一线） | `1..5` 等 |
| `line-width` | `appearance` | 不同符号/线条的线宽设置（轻/重线、连梁等） | 带 `type` 属性的数值 |
| `lyric-font` | 字体/歌词相关 | 歌词字体参数 | 容器/数值 |
| `measure` | `part` 内 | 小节容器（按时间顺序组织事件） | 容器 |
| `metronome` | `direction-type` | 节拍器/速度标记容器（例如 “♩=129”） | 容器 |
| `midi-channel` | `midi-*`相关 | MIDI 通道号 | `1..16`（通常为数值） |
| `midi-device` | `midi-*`相关 | MIDI 设备标识 | 数值/标识 |
| `midi-instrument` | `midi-*`相关 | MIDI 乐器分类/映射标识 | 数值/标识 |
| `midi-program` | `midi-*`相关 | MIDI Program Number（音色编号） | `0..127` |
| `millimeters` | 布局单位声明 | 毫米单位相关的声明/换算 | 数值 |
| `miscellaneous` | 文件头 | 杂项信息容器（不属于主结构的额外信息） | 容器 |
| `miscellaneous-field` | `miscellaneous` | 杂项字段（通常是 name/value） | `creationDate` 等 |
| `music-font` | 字体配置 | 记谱字体参数 | 容器/数值 |
| `normal-notes` | `time-modification` | 复拍的“正常情况下对应音符数量” | `2` 等 |
| `normal-type` | `time-modification` | 正常参照情况下的音符类型（定义对照时值） | `half`/`quarter` 等 |
| `notations` | `note` | 音符的附加记号总容器（连音、装饰、特殊符号等） | 容器 |
| `note` | `measure`内 | 音符/事件本体（可以包含音高、时值、记号等） | 容器 |
| `note-size` | 字体/尺寸配置 | 音符尺寸相关参数 | 数值/容器 |
| `octave` | `pitch` | 八度（决定音高落在哪个八度组） | `0..9` 等 |
| `page-height` | `page-layout` | 页面高度 | 数值 |
| `page-layout` | `print`相关 | 页面布局容器 | 容器 |
| `page-margins` | `page-layout` | 页面边距容器 | 容器 |
| `page-width` | `page-layout` | 页面宽度 | 数值 |
| `pan` | `sound` | 声像（左右平衡）参数 | 数值 |
| `part` | `score-partwise` 内 | 一个声部（乐器）内容块（包含多个 `measure`） | 容器 |
| `part-abbreviation` | `score-part` | 声部缩写 | 字符串 |
| `part-list` | 文件头结构 | 声部列表容器 | 容器 |
| `part-name` | `score-part` | 声部名称 | `Piano` 等 |
| `per-minute` | `metronome` | 每分钟的节拍数（速度数值） | 数值 |
| `pitch` | `note`（非休止） | 音高容器（由 `step/alter/octave`等组成） | 容器 |
| `print` | 文件头 | 打印/排版支持与布局相关声明容器 | 容器 |
| `rest` | `note` | 休止符容器（表示该 `note` 是休止） | 容器/空 |
| `right-margin` | `page-margins` | 右边距 | 数值 |
| `scaling` | 布局/缩放 | 缩放参数容器 | 容器/数值 |
| `score-instrument` | `score-part` | 声部对应的乐器/声音条目 | 容器 |
| `score-part` | `part-list` | 一个声部条目（id + 乐器信息） | 容器 |
| `score-partwise` | 根 | 分轨（按 `part`组织）的 MusicXML 类型 | 根元素 |
| `sign` | `clef` | 谱号类型（高音/低音/中音等；例如 `G`/`F`） | `G` / `F` |
| `software` | 文件头 | 生成该 MusicXML 的软件名称 | 如 `MuseScore Studio ...` |
| `sound` | `note`或`direction`相关 | 声音/演奏相关参数容器（音量、力度、持续等） | 容器 |
| `staccato` | `articulations` | 断音记号（staccato） | 空元素/容器 |
| `staff` | `note`或`measure`内 | 第几条谱表（多谱表乐器时区分） | 数字 |
| `staff-distance` | `staff-layout` | 谱表间距 | 数值 |
| `staff-layout` | `print`相关 | 谱表布局容器 | 容器 |
| `staves` | `staff-layout` | 谱表数量 | 数值 |
| `stem` | `note` | 符干方向（`up`/`down`） | `up` / `down` |
| `step` | `pitch` | 音阶字母（A~G 的自然音） | `C D E F G A B` |
| `supports` | `encoding` | 支持能力声明（例如哪些符号/排版能力导出） | 带属性元素 |
| `system-distance` | `system-layout` | 系统间距 | 数值 |
| `system-layout` | `print`相关 | 系统（同一行的谱系统）布局容器 | 容器 |
| `system-margins` | `system-layout` | 系统边距容器 | 容器 |
| `tenths` | 布局单位 | 十分之一单位（与 `millimeters` 等一起决定实际尺寸） | 数值 |
| `tie` | `notations` | 连音线（tie）起点信息（连接关系的类型由属性/子节点给出） | `start/stop` 等语义（取决于文件） |
| `tied` | `notations` | 连音线的延续端信息（与 `tie`配对） | `start/stop` 等语义（取决于文件） |
| `time` | `attributes` | 拍号容器 | 容器 |
| `time-modification` | `tuplet`相关 | 复拍的时间比例修正（tuplet 的节奏缩放） | 容器 |
| `top-margin` | `page-margins` | 页面上边距 | 数值 |
| `top-system-distance` | `print/page`布局 | 从页面顶部到首个系统的距离（或系统顶部间距） | 数值 |
| `tuplet` | `note/notations`附近 | 复拍结构容器（例如三连音整体） | 容器 |
| `type` | `note` | 记谱时值类型（例如 `quarter`、`half`；对应“名义时值/外形”） | `quarter` / `half` / `whole` 等 |
| `voice` | `note` | 声部编号（同一 `staff` 内的不同层/同时事件） | `1/2/...` |
| `volume` | `sound` | 音量参数 | 数值 |
| `word-font` | 字体配置 | 文字/文本类元素的字体参数 | 容器/数值 |
